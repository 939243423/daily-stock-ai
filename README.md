## 📖 项目介绍

**AI 股市雷达** 是一个基于 **GitHub Actions** 和 **混合专家模型 (MoE)** 架构的全自动量化分析工具。

它每天会自动运行，利用全球顶尖的 AI 模型为您挖掘 A 股市场机会：

1.  **数据校准**：自动联网获取 A 股实时行情与主力资金数据。
2.  **多模型博弈**：采用 **“四级火箭”** 机制进行深度扫描：
    * 🚀 **OpenAI GPT-4o**：负责核心逻辑推理与策略把控。
    * 🇨🇳 **阿里通义千问 (Qwen-Max)**：专精 A 股政策解读与资金流向分析。
    * 🐋 **DeepSeek-V3**：挖掘低估值与高成长性的潜力标的。
    * ✨ **Google Gemini**：提供全球视角的风控与辅助判断。
3.  **策略筛选**：基于“低估值、主力介入、基本面稳健”三大逻辑，最终输出 3 只高潜力个股。
4.  **自动部署**：分析报告生成后，自动构建静态网站并推送到 **Cloudflare Pages** 进行全球分发。
